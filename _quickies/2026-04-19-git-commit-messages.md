Write clear commit messages! Use this format:

```
[Type] Brief summary (50 chars max)

Detailed explanation if needed.
- List specific changes
- Be descriptive
```

**Types:**
- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation
- `refactor:` Code improvement
- `test:` Test additions

Good commits make code reviews and future maintenance so much easier!
